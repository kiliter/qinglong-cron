# 禁用 brainstorming 技能设计说明

## 背景

当前项目根目录不存在 `AGENTS.md`。为统一项目内代理的工作规则，需要创建标准名称的项目级指令文件，并明确禁止在本项目中触发或使用 `brainstorming` 技能。

## 目标

- 在项目根目录创建 `AGENTS.md`。
- 保留用户指定的中文回复、代码注释和中文文档规则。
- 增加本项目禁用 `brainstorming` 技能的明确规则。
- 不修改业务代码、任务脚本或其他项目配置。

## 文件内容设计

`AGENTS.md` 将包含以下规则：

1. 始终使用中文回复。
2. 生成的方法和代码需要添加注释与必要说明。
3. 生成文档必须使用中文，专业术语可以保留原语言。
4. 本项目禁止触发或使用 `brainstorming` 技能；相关任务直接按用户要求分析和执行。

## 影响范围

该变更仅影响遵循项目根目录 `AGENTS.md` 的代理行为，不改变应用运行逻辑、定时任务、测试或部署流程。

## 验证方式

- 确认根目录文件名为标准大写形式 `AGENTS.md`。
- 检查四条规则均已写入且表述无歧义。
- 检查 Git 变更中没有业务文件被意外修改。
